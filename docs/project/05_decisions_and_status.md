# 決定事項と進捗（2026-10-05）

## 製品構成
- 2ライン：STUDIO（DAW向け、109本）／LIVE（配信・PA向け、30本）。当初120本予定から約140本に拡大。
- カテゴリ記号：EQ・CS（EQ/ストリップ）、DY・MS（ダイナミクス/マスタリング）、SA・LO・GT（倍音/低域/ギター）、RV・DL・MD・ST（空間・時間）、VO（ボーカル）、RS（修復）、CR・IN・UT（クリエイティブ/楽器/ユーティリティ）、MT（計測）、LV（LIVE）。
- 製品名は「SW」＋カテゴリ2文字＋2桁番号（例 SW EQ05）。

## 技術・法務
- VST3（SDK v3.8 はMITで商用可）＋AU＋CLAP。OBSネイティブはGPL-2でソース公開が必要になるため、VST3形式で提供しOBSのVST3ホストで使う。
- VST2は新規ライセンス不可なので使わない。AAXはAvid契約が別途必要なので後回し。
- 実機名・ロゴ・製品名は使わない。外観全体（トレードドレス）の模倣も避ける。パラメータの考え方を参考にするのはよい。

## 見た目
- STUDIO：実機風アナログラック（オリジナル外観）とデジタルの混在。筐体は2Uラック46・デジタル62・500シリーズ1。LIVE：ロードケース30。
- カテゴリ色をラックイヤー・指針・点灯ボタン・型番バッジに使う。状態色（緑黄赤）とは混ぜない。クリップ通知は赤でなく反転点滅。
- Blenderで写実部品を描画（ノブ4種・トグル・ネジ・イヤー・パネル素材8種・LIVEコーナー金具・フェーダー・VUベゼル）。ノブは本体静止・指針だけ回す。
- 目標は「100万円で売れそうな」プロの見た目。

## 全製品共通の機能（139本に標準装備）
- モーフ（2プリセット間の連続補間、オートメーション可）／EVOバー（進化機能の1行説明・SW Link・Unit A/B/C・操作履歴・Low lat・オーバーサンプリング）／Auto gain（バイパス前後の音量合わせ）／Δ（差分試聴）。
- 各製品に固有の「進化機能」を1つ（一覧は 03 の evo 列）。名機の操作をなぞるだけにしない方針。
- LIVE：ゼロ遅延が原則（遅延が出る処理は値を常時表示）、値は常に数値表示、Lock・Remote・OBSシーン連動（LV27）。

## 次の作業：仕様書
製品ごとに以下を書く。共通機能は共通章にまとめ、製品ごとには差分だけ。
1. 概要（何をするか・用途・ライン）
2. パラメータ表：名前／範囲／単位／既定値／カーブ（対数・直線）／オートメーション可否（土台は 04_parameters.csv）
