## Claudeへの指示（プロジェクト指示にも貼る）
- 日本語で、結論から簡潔に。決定済みの仕様（05）とデザインシステム（01・02）を前提にし、勝手に変えない。
- 製品の数値・パラメータは 03・04 を正とする。画面の値と仕様書の値がずれる場合は指摘してから決める。
- 実在機材の名前・ロゴ・外観は使わない。裏付けのない数値（遅延0msなど）は販売コピーに入れない。
- CPU目安などの見積もりは「設計上の見積もり」と明記し、実測値と区別する。
- 状態色（緑・黄・赤）とカテゴリ色を混ぜない。光は左上から一方向。
