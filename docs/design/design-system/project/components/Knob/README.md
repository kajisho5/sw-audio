回転操作子。アナログ（Blender描画）・セレクター・デジタル弧・LEDリングの4系統。

- アナログノブ：本体は静止画（Blender描画：black / alu / ivory / rubber）。回転するのは指針（カテゴリ色の線）だけ。光の向きが変わらないので実機と同じ見え方になる。実装時もフィルムストリップ不要（本体画像1枚＋コードで指針描画）。
- 目盛り：主目盛り27°刻み・細目盛り13.5°刻みの2段。範囲は-135°〜+135°。両端の値を range スタイルで表示。
- セレクター（alu）：段階スイッチ用。目盛りは選択肢の数だけ。
- デジタル弧ノブ：外周の弧がカテゴリ色で値を示す。中心は暗いノブ、指針は光る点。
- LEDリング（LIVE）：32分割のLED。点灯色は cat-*-ring。値は必ず数値でも併記。
- サイズ：主64px（size-knob-main）、小40〜48px、大72〜84px。
