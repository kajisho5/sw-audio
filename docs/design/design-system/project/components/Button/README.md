押しボタン類。物理ボタン（btn）、デジタルボタン（dbtn）、LIVEチップ（chip）。

- 物理ボタン：ui-control-hi → ui-control のグラデーション、shadow-button。点灯時は cat-*-hi → cat-* のグラデーションと発光（shadow-lit）。文字は button スタイル。
- デジタルボタン：ui-control 地、ui-line の枠、radius-sm。
- LIVEチップ：高さ44px以上、live-chip スタイル、点灯は cat-*-ring。
- Δ（差分試聴）と Auto（オートゲイン）は全製品のパネル上段に置く。
