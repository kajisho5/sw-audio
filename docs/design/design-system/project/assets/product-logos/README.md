# 製品名のロゴタイプ

## SWINGBY（SW IN07、軽量プリセットシンセ）

名前は依頼者の決定（2026-10-08）。商標の調査はまだしていない（正式に使う前に J-PlatPat・USPTO・EUIPO の第9類を確認する）。

| ファイル | 色 | 使う地 |
| --- | --- | --- |
| `swingby-dark.svg` | SW＝cat-creative（#22a87c）、INGBY＝sw-white（#F0F0F0） | 暗い地（画面のダーク、販売素材） |
| `swingby-light.svg` | SW＝cat-creative（#22a87c）、INGBY＝sw-black（#050505） | 明るい地（画面のライト） |
| `swingby-white.svg`・`swingby-black.svg` | 1色 | 1色しか使えない所（印刷、刻印、透かし） |
| `swingby-mono.svg` | currentColor | 画面で文字色に合わせるとき |

- **字形：** SW AUDIO のワードマーク（LOGO.md）の字形の仕組みをそのまま使った。S・W・I はワードマークの配布データと同じ形（無変更）。N・G・B・Y は同じ中心線の高さ（字高 56 のうち線の中心 3.22〜52.78）、同じ線幅 6.44、丸い端・丸い角、O・D と同じ角の半径 15（B のふくらみは 12 ＝ S の輪と同じ考え方）、文字の間隔 11.4（ワードマークと同じ）で新しく描き、輪郭にした（塗りのパスだけ）。
- **色：** 頭の「SW」だけをカテゴリ色にして、ブランド名が入っていることを見せる。LOGO.md の「ワードマークにカテゴリ色は使わない」は SW AUDIO のワードマークの規定で、製品名のロゴタイプには定めがないため、記号をカテゴリ色にする規定に合わせて決めた（設計値）。グラデーション・影・発光は付けない。1色版も用意した。
- **やらないこと：** 縦横比の変更、回転、字間の変更、書体での打ち直し、SW と INGBY の色を入れ替える・別の色にする。
- **作り直し：** `tools/logo/swingby_wordmark.py <SW AUDIO ワードマークの SVG> <出力先>`（skia-pathops が要る）。SW AUDIO ワードマークの SVG はデザインシステムの配布データ（このリポジトリには入っていない。IN07 キャンバスの素材にある）。
