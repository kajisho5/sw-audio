# SW AUDIO Design System

SEVENTHWELL のオーディオプラグイン・バンドル「SW AUDIO」のデザインシステム。STUDIOライン約110本とLIVEライン30本、計約140製品の画面・販売素材は、すべてこの記録に従う。

- **全製品の画面：** [SW AUDIO キャンバス](https://claude.ai/artifact/YZPBvqpqrqoVXhZShrEBhE)（141アートボード＋販売素材＋ロゴ案）
- **記録日：** 2026-10-05
- **関連セクション：** [LOGO.md](LOGO.md)（ロゴの使用規定） / [RENDERING.md](RENDERING.md)（Blender描画部品の作り方）

## 1. ブランドの位置づけ

| 階層 | 名前 | 役割 |
|---|---|---|
| 親ブランド | SEVENTHWELL | 映像・音響制作会社。モノクロ（#050505 / #f0f0f0）、ワイドな全大文字、ミニマル |
| 製品ブランド | SW AUDIO | プラグインバンドル。親ブランドのモノクロ規定は適用しない（色を使ってよい） |
| ライン | STUDIO | DAW向け。実機風アナログラック＋デジタルの混在 |
| ライン | LIVE | 配信・PA向け。ロードケース風、常時数値表示、ゼロ遅延の原則 |

製品名は「SW」＋2文字のカテゴリ記号＋2桁の連番（例：SW EQ05、SW LV03）。

## ロゴ

SW AUDIO のロゴは **Rack Ear**：全製品の両端にある色分けラックイヤーを、そのままマークにしたもの。記号は製品のカテゴリ色をとり、ワードマーク「SW AUDIO」は専用字形。規定は LOGO.md、データは assets の Logo。

## 2. デザイン原則

1. **ひと目で何のプラグインか分かる。** カテゴリ色のラックイヤーと型番バッジで、カテゴリを形と色の両方で示す。
2. **実機の質感、オリジナルの外観。** 実在機材の名前・ロゴ・外観全体（トレードドレス）は真似しない。操作パラメータの考え方を参考にするのはよい。
3. **操作系も進化させる。** 名機の操作をなぞるだけにしない。全製品に「進化機能」を1つ持たせ、EVOバーで説明する。
4. **光は左上から一方向。** ノブ・ネジ・パネル・ボタンのハイライトと影はすべて左上光源で揃える。ノブを回しても光は動かない（指針だけ回る）。
5. **状態色とカテゴリ色を混ぜない。** 緑・黄・赤は状態専用。

| Saturation | SA・LO・GT | #e0693f | #ffb08f | #8c3417 | #ff8a5c |
| Space・Time | RV・DL・MD・ST | #7a6be0 | #b7adff | #3c3289 | #9a8df0 |

- 型番バッジは「カテゴリ色の地＋濃色文字（#0c0c0d）」。全カテゴリで4.7:1以上（Space・Timeが最小4.7:1）。
- **既知の課題：** EQ（青）・Space（紫）・Vocal（ピンク）は明度が近く（地に対し4.5〜4.8:1）、色相だけで区別している。色覚特性によっては見分けにくいため、型番バッジの文字（EQ / RV / VO）を必ず併記する。

### 状態色

| 用途 | トークン | 値 | ルール |
|---|---|---|---|
| 正常・接続・信号あり | state-ok | #2bd14a | LED、SW Link、メーター下段 |
| 注意 | state-warn | #f0c93d | メーター中段 |
| 超過 | state-over | #e0443e | メーター最上段とVU赤ゾーンだけ（計測慣習上の例外） |

クリップの通知は赤ではなく**反転点滅**で出す。

### 文字色（ui-ground #101113 上のコントラスト）

text-1 #e8e8e8（ラベル 15.4:1）／ text-2 #cacaca（数値 11.5:1）／ text-3 #b8b8b8（刻印 9.5:1）／ text-4 #a8a8a8（目盛り値 7.9:1）／ text-5 #8e8e8e（補足 5.8:1）。text-5より暗い文字は使わない。

## 4. 書体

| 役割 | 書体 | 使いどころ |
|---|---|---|
| Display | Michroma | 型番（plate 20px / 0.2em）、ツールバー製品名、販売素材の見出し |
| UI | Barlow Condensed | ラベル（12px 600 0.16em 大文字）、刻印（11px 500 0.24em）、ボタン |
| Mono | Space Mono | 数値、型番バッジ、EVOタグ、LIVEの常時表示数値 |
| 日本語 | Noto Sans JP | 販売素材・資料のみ。プラグインUI内に日本語は入れない |

すべてGoogle Fontsで配布されている書体。ロゴのワードマークは書体ではなく、パスで組んだ専用字形（LOGO.md）。ロゴの文字を書体で打ち直さない。

## 5. 筐体（4種）

| 筐体 | ライン | 特徴 | 例 |
|---|---|---|---|
| 2Uラック | STUDIO | 左右44pxのラックイヤー、素材パネル、四隅ネジ | EQ01, DY06, SA01 |
| 500シリーズ縦型 | STUDIO | 縦長モジュール、イヤーなし | DY04 |
| デジタルフラット | STUDIO | 大型ディスプレイ＋弧ノブ、地は ui-deck | EQ02, EQ07, RV01 |
| ロードケース | LIVE | スチール枠＋ボール型コーナー金具、LEDリング | LV01〜LV30 |

縦の構成は全筐体共通：**ツールバー（40px＋3pxストリップ）→ 本体 → EVOバー（30px）**。

## 6. パネル素材（Blender描画のテクスチャ8種）

crinkle（縮み塗装）／ graphite（グラファイト粉体塗装）／ tolex（トーレックス）／ anodized（ブラックアルマイト）／ olive（オリーブ塗装）／ brushed（ヘアラインアルミ・横筋）／ bronze（ブロンズヘアライン）／ walnut（ウォールナット）。

素材は製品ごとに個別に割り当てており、カテゴリとは連動しない。指定がなければ crinkle。現在の例：SA01 Tape＝brushed、SA03 Tube＝olive、SA04 Transformer＝bronze、SA07 Lo-fi＝tolex、GT01 Amp＝tolex、DY06 Vari-Mu＝graphite。

## 7. 操作子

- **アナログノブ：** Blender描画の本体（black / alu / ivory / rubber）＋カテゴリ色の指針。目盛りは主27°・細13.5°の2段、範囲±135°。
- **セレクター：** alu本体、選択肢の数だけ目盛り。
- **デジタル弧ノブ：** 外周の弧が値、中心に光る点の指針。
- **LEDリング（LIVE）：** 32分割、点灯色は cat-*-ring、数値を必ず併記。
- **ボタン：** 物理（btn）／デジタル（dbtn）／LIVEチップ（chip、高さ44px以上）。
- **トグル：** Blender描画のクロームレバー（上下2状態）。
- **フェーダー：** Blender描画のアルミキャップ。

## 8. 全製品共通の機能（139本に標準装備）

1. **モーフ：** ツールバーの A━●━B。2プリセット間を連続補間、オートメーション可。
2. **EVOバー：** 最下部。進化機能の1行説明／SW Link／Unit A/B/C（アナログ系の個体差）／操作履歴／Low lat／オーバーサンプリング。
3. **Auto gain：** バイパス前後の音量を揃える。
4. **Δ：** 変化した成分だけを試聴する。

STUDIOツールバー：プリセット・モーフ・Auto gain・Low lat・2×OS・表示倍率・Undo/Redo。
LIVEツールバー：LIVE遅延表示・Scene選択・Remote・Lock。LIVEのEVOバーにはCPU%を出す（STUDIOとの識別点）。

## 9. LIVEラインのルール

- ゼロ遅延が原則。遅延が出る処理（先読みリミッターなど）は遅延値をツールバーに常時表示する。
- 値は常に数値で表示する（ノブの角度だけで読ませない）。
- Lockで本番中の誤操作を防ぐ。Remote（外部操作）とOBSシーン連動（LV27）に対応する。

## 10. 販売素材

- ヒーロー画像は Blender で筐体を立体描画したもの（キャンバスの MK01 STUDIO / MK02 LIVE）。
- 構成：左に見出し（Michroma 64px）＋日本語コピー（Noto Sans JP 26px 700）＋英語サブ＋統計3つ、右に製品。
- 実装前で裏付けのない数値（例「0 ms」）はコピーに入れない。

## 11. 技術・法務の前提

- 形式：VST3（SDK v3.8はMITライセンス）＋ AU ＋ CLAP。OBSはVST3ホスト経由。AAXは後回し（Avid契約が別途必要）。VST2は新規ライセンス不可のため使わない。
- 実機名・ロゴ・製品名は使わない。外観全体の模倣（トレードドレス）にも注意する。
- ロゴは C Rack Ear で暫定確定（LOGO.md）。ツールバー左端は「記号（カテゴリ色）＋ SW AUDIO」。
