# Blender描画部品

写実的な部品は Blender 4.0.2（Cycles、CPU）で描画し、WebPにして画面に埋め込む。照明はすべて左上キー＋右下フィル＋リムの同一スタジオ設定。

## 決まりごと

- ノブ本体は回さない。回すのは指針だけ（光の向きが変わらないため）。実装時もフィルムストリップは不要。
- ノブ画像は本体の外側に影の余白を含む。本体の直径＝要素サイズにするため、画像は要素の135%で配置する（inset -17.5%）。
- 作業環境にOIDN（ノイズ除去）がないため、高サンプルで描画し、OpenCVでノイズ除去している。
- ヘアラインアルミ・ブロンズの筋は横方向（ラック機器で一般的）。
- 販売用ヒーロー画像は、パネル画面を2倍解像度で取り込み、立方体の前面に貼って描画する（2400×1350、40サンプル）。
