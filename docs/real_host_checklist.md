# 実機（DAW）での確認リスト

CI とクラウド環境でできることは全部やってある（単体テスト、clap-validator、Steinberg validator、auval、ホスト経由の音声経路テスト、全画面のブラウザ描画）。
**以下は、実際の DAW とお使いの OS でしか確かめられないこと。** 試すときは「項目 → 期待する動き」を見て、違ったら項目の番号と、DAW・OS・プラグイン形式（CLAP／VST3／AU）を控えてください。
CI の成果物（Actions の実行結果の「Artifacts」）にビルド済みのプラグインが入っています。

## 0. まず読み込めるか

| # | 項目 | 期待する動き |
| --- | --- | --- |
| 0-1 | プラグインのスキャン（VST3／AU／CLAP のどれか） | DAW のスキャンが止まらず、製品が一覧に出る（SW で始まる名前） |
| 0-2 | 1 つ挿して、音を通す | 既定値では音が変わらない（EQ・ダイナミクス系は素通し、色付け系は軽く変わる）。ノイズ・クリックが出ない |
| 0-3 | プロジェクトを保存して開き直す | つまみの位置が戻る。画面を閉じて開いても同じ |
| 0-4 | バイパス（DAW 側）と、プラグイン内の Bypass | 音が元に戻る。切替でプチッと鳴らない |
| 0-5 | リバーブ・ディレイ（RV01〜RV06・DL01〜DL05・LV24・LV25・GT03 など）を挿したトラックの書き出し／フリーズ（バウンス） | 素材の終わりのあとに残響・繰り返しが切れずに入る（プラグインは「テール」の長さを DAW に伝える：CLAP の tail 拡張、VST3 の getTailSamples。DAW が使うかは DAW しだい。使わない DAW では、書き出しの終わりに無音を足す） |
| 0-7 | リバーブ・ディレイを挿して、再生を止める／ループの頭へ戻る／再生位置を飛ばす | 前の位置の残響・繰り返しが飛んだ先で鳴らない（DAW が `reset()` を呼ぶ場合。クラウド環境では `sw-host-smoke --reset` で、`reset()` のあと −40 dBFS を超えて鳴る製品が無いことを確認済み） |
| 0-6 | DAW のバッファの大きさを変える（32〜2048）、または再生中にオートメーションを書く | 同じ音になる（クラウド環境では `sw-host-smoke --blocks` で、1・7・64・509・1024・混合・2048 のブロックが 256 と同じ結果になることを全製品で確認済み。GT02・RV04・ST05 だけ、IR の入れ替えの時刻がブロック長で変わる） |

## 1. 画面（WebView）

画面は macOS＝WKWebView、Windows＝WebView2 に載せています（Linux は画面なし）。Windows では WebView2 ランタイムが必要です（入っていない環境で画面が出るかは未確認）。

| # | 項目 | 期待する動き |
| --- | --- | --- |
| 1-1 | 画面を開く（どの製品でも） | 設計どおりの画面が出る。フォントが崩れない（Barlow Condensed・Space Mono・Michroma は同梱） |
| 1-2 | つまみを上下にドラッグ、Shift でゆっくり、ダブルクリックで初期値、ホイール | 値が動き、**DAW のオートメーション記録に残る**（書き込みモードで確認） |
| 1-3 | DAW 側でオートメーションを再生 | 画面のつまみが追従して動く |
| 1-4 | 画面を開いたまま再生 | 入出力メーター・スペクトラム・GR 表示が動く。CPU 表示が出る |
| 1-5 | 画面を開閉・複数のインスタンスを同時に開く | 落ちない。重くならない |
| 1-6 | ウィンドウの大きさ・高 DPI の画面 | 固定サイズ（製品ごとのデザインの大きさ）。ぼやけない／はみ出さない（拡大縮小は未実装） |
| 1-7 | キーボード（DAW のショートカット） | 画面の上でも DAW のキー操作が効くこと（効かないのは既知の制限かもしれないので控える） |

## 2. 画面から動く機能（実機でだけ確かめられるもの）

| # | 項目 | 対象 | 期待する動き |
| --- | --- | --- | --- |
| 2-1 | **ファイルを選ぶ** | UT03 の Load B／C、RV04 の Load IR | ファイル選択ウィンドウが出る。WAV・AIFF（+ MP3・FLAC・AAC は WebView が読めれば）が読める。読み込み中に音が途切れない |
| 2-2 | **大きいメッセージ** | UT03 の長い曲（数分） | 20 分まで。固まらない・途中で失敗しない（失敗したら画面に「failed」が増える） |
| 2-3 | **プリセットの保存・呼び出し** | 全製品の上部のメニュー | 保存先は `~/Documents/SW AUDIO/Presets/<製品>/`（Windows は「ドキュメント」フォルダ）。名前を付けて保存・読み込み・削除ができる |
| 2-4 | **Undo／Redo と履歴（時計）** | 全製品 | つまみのドラッグ 1 回が Undo 1 段。時計を押すと変更の一覧が出て、押した行の前まで戻る |
| 2-5 | **ログの書き出し** | LV23 の Export log、LV30 の録音 | `~/Documents/SW AUDIO/…` に CSV／WAV ができる |
| 2-6 | **トラック名の受け取り** | UT01 | EVO バーの行が「Vocal track: …」のように変わる（ホストが CLAP track-info／VST3 のチャンネル情報を渡す場合だけ。渡さないホストでは「Track kind unknown」） |
| 2-7 | **SW Link** | 全製品のランプ、EQ02 の Unmask | **同じ DAW プロセスに SW AUDIO を 2 つ以上挿す**とランプが点灯し、ツールチップに数が出る。EQ02 の Unmask を押し、別のトラックの SW AUDIO に音を通すと、重なる帯域が赤く塗られる。**プラグインを 1 つずつ別プロセスで動かす設定の DAW では届かない**（ランプは消灯のまま、メッセージが出る） |
| 2-8 | **Assist** | EQ02 | 2 秒以上音を通すと、橙の三角が出る。三角を押すと Bell が置かれる |
| 2-9 | **Low lat** | EQ02・EQ07・EQ08・DY05・DY08・MS02 | 押すと遅延の設定が変わり、DAW の遅延補正が追従する（再生を止めて再開が必要な DAW もある） |
| 2-10 | **2× OS（オーバーサンプリング）** | EVO バーの「2× OS」があり、非線形の段を持つ製品（EQ01・EQ03〜EQ06、CS01・CS03・CS04、DY01・DY06・DY09、GT01・GT04、SA01〜SA06、CR01、MS06） | 押すたびに 1×→2×→4× と進み、表示が変わる。1× は CPU が軽く高域の折り返しが出やすい／4× は重い。**再生中に切り替えると、その瞬間に 1 回プチッと鳴る**（既知。保存した設定の読み込みでは鳴らない） |
| 2-11 | **Unit A／B／C** | EVO バーに A／B／C があり、Unit を持つ製品（EQ03〜EQ06・EQ09、CS01〜CS03、DY06・DY07、GT01・GT04・GT05、SA01〜SA04 など 42 製品） | 押すと切り替わる。B・C にすると左右の音が **ごくわずかに** 違う（EQ の山や谷の位置が左右で 3 ％以内ずれる、左右のレベルが 0.3 dB 以内違う、飽和の入り方が 0.5 dB 以内違う）。A は左右がそろう。Mix や In のオフでは原音のまま。再生中に切り替えても、プチッと鳴らない（20 ms でなめらかに動く） |
| 2-12 | **Learn／Set input／Auto** | DY04・CS02・RV08 の Learn、CS03 の Set input（EVO バーの文の隣）、DY10 の Auto（パネルのボタン） | **DY04・CS02・RV08：** ドラムのトラックで Learn を押して叩く（最長 30 秒。もう一度押すと止まる）。字が「Listening: 12 hits (press to finish)」になり、終わると Gate／Threshold と（DY04 は Key HPF／LPF の周波数、CS02 は内部のキーフィルター、RV08 は Snare key が On）が書かれる。**ホストのオートメーションに値の変化が記録される**。結果が使えない素材（打撃と被りが同じ大きさ）では何も変わらない。**DY10 の Auto：** 押して再生中のミックスを 10 秒以上聴かせる（「Listening 42 %」。聴いている間にもう一度押すと取り消し）。終わると Crossover 1〜3 が動く。**Undo を 1 回押すと 3 つとも戻る**（Redo で再び）。**CS03：** Set input を押して 5 秒鳴らすと Gain のつまみが動く（平均 −18 dBFS RMS・ピーク −6 dBFS を目標。ピークの鋭い音は RMS が低く残る） |
| 2-13 | **Truncation check** | MS07 のパネルのボタン | 押して 5 秒以上、信号を通す（無音は数えない）。「Checking 42 %」→「Input: 16 bit grid」などになる。**16 ビットの WAV をそのままの音量で通すと 16 bit**、音量を変えたり処理したりしたものや、32 bit float の素材は「float」。ツールチップに Bits との関係が出る |
| 2-14 | **Suggest order** | CS04 の EVO バーのボタン | 押すと音源の種類（Voice／Vocal／Drums／Bass／Mix bus）のメニューが出る。選ぶとモジュールのカードが並び替わり、音も切り替わる（5 ms で下げて入れ替え、戻す）。Undo で戻る。**規則表（README）の並びが実際の素材で妥当か、耳で** |
| 2-15 | **Match（EQ05）** | EQ05 の EVO バーの「Reference」と「Match」 | 「Reference」で音声ファイル（WAV・MP3 など）を選ぶ。**ウィンドウへのドロップも試す**（WKWebView・WebView2 で届くか未確認）。読み込めるとボタンにファイル名が出る（40 秒より長い曲は全体から 5 秒×8 か所を送る）。参照が無いときの「Match」はファイルを選ぶ窓を開く。参照を入れて「Match」を押し、**入力を 10 秒以上再生する**（無音は数えない）→「Listening 42 %」→「Fitting …」→「Matched」。HF／HMF／LMF／LF の Gain・Freq・Q・Shape の 12 個が動き、**DAW のオートメーション記録にも出る**。ツールバーの Undo 1 回で 12 個とも戻る。**実際の曲どうし（参照と、直したい録音）で聴いて、音色が参照に近づくか**（試験は雑音で数値を見ただけ）。再生を止めたまま押しても進まないこと、聴いている間にもう一度押すと取り消せること。 | **参照はプロジェクトに保存されない**（開き直したら選び直し）。HPF・LPF・Drive・Output は触らない。UT03 の参照は SW Link 経由で「From UT03」から使える（次の項目 2-16）。 |
| 2-16 | **From UT03（SW Link）** | EQ05 の EVO バーの「From UT03」。UT03 は別のトラック（またはマスター）に挿す | 同じホストのプロセスに UT03 と EQ05 を挿し、UT03 の画面で参照ファイルを読み込む。EQ05 の「From UT03」が**点灯**し（読み込む前は薄い）、押すと参照が「UT03 reference」になる。その参照で「Match」を押して、入力を 10 秒以上再生する。UT03 の Source を B／C に切り替えると、出る参照が変わる（次のブロックで）。UT03 を外すと「From UT03」が薄くなる。**ホストがプラグインを別プロセスで動かす場合は見えない**（その場合は SW Link のランプも消えている）。 | 実際の DAW でのプロセスの分け方が不明（SW Link の 2-xx と同じ）。 |

## 3. 音（耳で）

README の各製品の節にある「測っていないもの」が、そのまま耳で確かめる項目です。特に：

- **色付け系（EQ01・EQ03〜EQ06、CS01〜CS04、SA01〜SA08、GT01〜GT05）**：Drive を上げたときの歪み方、音量補正（Auto gain の追従）。
- **リバーブ・空間（RV01〜RV08、ST05）**：合成した IR の聞こえ方（録音した IR は使っていません）、テールの切れ方。
- **ピッチ（VO01〜VO03・VO06）**：実際の歌声での追従、フォルマント。
- **ノイズ・修復（RS01〜RS07）**：Denoise の「ミュージカルノイズ」、Declick の誤検出。
- **ラウドネス（MT01・LV23・MS06）**：他社メーター（YouLean など）との数値の比較。
- **EQ02 の Assist／Unmask、EQ07 の Auto thresh、DY04・CS02・RV08 の Learn、CS03 の Set input、DY10 の Auto、UT01 の記憶**：設計値（しきい値・時定数）が実際の素材で妥当か。（Learn は合成のドラムでしか確かめていない。実素材で打撃と被りが 2 群に分かれるか、しきい値が妥当か）

## 4. 負荷

- バッファ 256 サンプルで RV04・ST05 が余裕少なめ（README に 512 以上を推奨と書いてあります）。
- 192 kHz では RV04・ST05・RS04・MS04 が比較的重い（クラウド環境の測定で 1 コアの 28〜38 %。実機では未測定。README「検証結果」）。
- 長時間（1 時間以上）通して、CPU が増え続けない・メモリが増え続けない。（クラウド環境では `sw-host-smoke --soak=120` で、各製品に 120 秒ぶんの音とランダムな操作を通し、同じ設定での処理時間とメモリが増えないことを確認済み。実時間で 1 時間以上は未確認）

## 5. 見つけたら

- 落ちた場合：DAW の名前とバージョン、OS、プラグイン形式、製品名、直前の操作。
