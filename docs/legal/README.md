実装との対応（ここに書いた事実の出どころ）：
- プラグインが外と通信するのは、利用者がライセンスの画面で ACTIVATE を押したときだけ（キーとこのパソコンのコードをライセンスサーバーへ。`ui/in07/app.js`。サーバーの住所 `kActivationServer` を入れたビルドだけ）。使用状況の送信（テレメトリー）はない。
- ライセンスキーは購入完了のページに表示する（メールでは送らない。送るなら送信サービスを決める）。キーはサーバーに保存しないが、Checkout Session から同じキーを作れるので、なくした人には Stripe で購入を確かめてから購入完了のページ（`/thanks?session_id=…`）を案内できる。
- 使わなくなったパソコンの解除は `/manage`（キーを入れて一覧から）、1 ライセンスあたり 365 日で 3 回まで（`MAX_DEACTIVATIONS`）。ライセンスファイルはオフラインで有効なまま残るため、回数を絞らないと 1 本のキーで何台でも使えてしまう。
- ライセンスサーバーが保存するもの：ライセンス ID、キーの SHA-256、Stripe の Checkout Session ID・PaymentIntent ID、製品、対象のメジャー版、作成日時、返金の印、有効化・解除したパソコンのコード（塩付きハッシュ）と日時。氏名・メールアドレス・キーそのものは保存しない（`server/license/schema.sql`）。
- 決済とその個人情報は Stripe が扱う（カード番号は SEVENTHWELL に届かない）。
- 体験版：起動から 30 秒後、そのあと 60 秒ごとに 3 秒の無音（`core/include/sw/demo_gate.hpp`）。
- 1 本 3 台まで（`server/license` の `MAX_ACTIVATIONS`、既定 3）。買い切り、メジャー版 1 のアップデートは無料（`core/include/sw/license.hpp`）。
