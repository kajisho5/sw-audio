# プライバシーポリシー

〔下書き。専門家の確認前〕 制定日：〔　〕　SEVENTHWELL（以下「当方」）

## 1. 扱う情報と目的

| 情報 | どこで | 目的 |
| --- | --- | --- |
| 氏名・メールアドレス・支払いの情報 | 決済代行の Stripe が取得・管理します。カード番号は当方に届きません | 決済、ライセンスキーのお知らせ、返金 |
| ライセンス ID、ライセンスキーのハッシュ値（キーそのものは保存しません）、決済の識別番号、購入した製品、日時 | 当方のライセンスサーバー | ライセンスの発行・有効化・返金の処理 |
| 「このパソコンのコード」（パソコンの識別子から作った塩付きハッシュ値。元の識別子はパソコンの外に出ません）、有効化の日時 | 当方のライセンスサーバー（有効化したときだけ） | 1 ライセンスあたりの台数（3 台）の管理 |
| 通信の記録（IP アドレスなど） | ライセンスサーバーを置くクラウド事業者〔Cloudflare〕 | 不正な利用の防止、障害の調査 |
| お問い合わせの内容 | 電子メール | お問い合わせへの回答 |

プラグイン（SWINGBY など）は、利用者がライセンスの画面で有効化を行ったときにだけ、ライセンスキーとこのパソコンのコードを当方のライセンスサーバーへ送ります。それ以外に、使い方などの情報を外へ送ることはありません。プリセット・画面の設定・ライセンスファイルは利用者のパソコンの中に保存されます。

## 2. 第三者への提供

法令に基づく場合を除き、本人の同意なく第三者に提供しません。決済は Stripe（Stripe, Inc. と関連会社）に、サーバーの運用は〔Cloudflare, Inc.〕に委託しており、それぞれの規約に従って扱われます。〔海外の事業者への提供・委託にあたる場合の記載：国名、その国の個人情報保護の制度、事業者の措置〕

## 3. 保存期間

ライセンスの記録は、ライセンスを使える間と、法令で求められる期間保存します。
